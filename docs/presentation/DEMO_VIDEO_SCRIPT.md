## Technical Setup

### Equipment Needed
- Screen recorder (OBS Studio / QuickTime)
- Microphone (clear audio)
- Browser with chazon.html
- Backend running locally or deployed
- Terminal window

### Pre-recording Checklist
- [ ] Backend running at http://localhost:8000
- [ ] Qdrant running on port 6333
- [ ] Cohere API key configured in .env
- [ ] chazon.html loaded in browser
- [ ] Test run all demo commands
- [ ] Prepare terminal with large font (18pt+)
- [ ] Set browser zoom to 125% for visibility
- [ ] Close unnecessary tabs/windows
- [ ] Turn off notifications

### Recording Settings
- **Resolution:** 1920x1080 (1080p)
- **Frame rate:** 30 fps minimum
- **Audio:** 48kHz, mono or stereo
- **Format:** MP4 (H.264)
- **File size:** < 100MB

---

## Editing Notes

### Transitions
- Fast cuts (no fades)
- Keep energy high
- Match narration to visuals

### Text Overlays
- Large, readable font (24pt+)
- High contrast (white text on dark background)
- Highlight key technical terms
- Use emojis sparingly (✓, ✗, 🚀)

### Music
- Optional: Low volume background music
- Upbeat, tech-oriented
- Royalty-free (YouTube Audio Library)

### Export
- MP4 format
- H.264 codec
- 1080p resolution
- Upload to YouTube (unlisted or public)
- Share link in hackathon submission
