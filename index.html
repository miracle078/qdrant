🎯 What is Chazon?

Chazon (חזון - "Vision") is an open source AI-powered medical imaging analyzer for X-ray, MRI, and CT scans. Built for the lablab.ai Qdrant Challenge.


Helps radiologists and medical professionals:

  • Analyze X-rays - Detect abnormalities in chest X-rays, bone fractures, etc.
  • Process MRI scans - Multi-sequence viewing (T1, T2, FLAIR, DWI)
  • Review CT scans - Multi-planar reconstruction with Hounsfield unit measurements
  • Semantic Search - Find similar cases using Qdrant vector database
  • AI Analysis - Automated findings detection and diagnosis assistance

🏥 Features

Multi-Modality

X-Ray, CT, MRI, Ultrasound, PET, Mammography support

DICOM Compliant

Full DICOM standard with window/level presets

AI-Powered

Semantic search and abnormality detection

Modular

100+ markdown modules, <250 tokens each

⚡ Quick Start

Option 1: Try Online

  • Visit https://teslasolar.github.io/qdrant/frontend/
  • No installation required!

Option 2: Run Locally

  • Clone: git clone https://github.com/teslasolar/qdrant
  • Open: frontend/index.html in your browser

Option 3: Full Stack with Qdrant

  • Start Qdrant: docker run -p 6333:6333 qdrant/qdrant
  • Install deps: pip install -r requirements.txt
  • Run backend: python backend/api.py

🧬 Technology Stack

  • Frontend: Vanilla JS (no frameworks!)
  • Medical Imaging: Custom DICOM viewer, window/level engine
  • Vector Search: Qdrant for semantic similarity
  • AI Analysis: OpenAI embeddings + custom models
  • Language: SNT (Space-Time Notation) - trinary quantum computing
  • Architecture: Markdown-first modular design
