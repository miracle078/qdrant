Usage

Test models in the frontend terminal:

# List available models
models:list

# Download a model
models:download bert-tiny

# Load a model
models:load bert-tiny

# Check backend info
models:backend

# Benchmark performance
models:benchmark mobilenet-v3

# Test X-ray analysis
models:test-xray

# Show cache info
models:info
