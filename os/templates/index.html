📄 Templates System

Perspective-Style Templates

Inspired by Ignition Perspective, our template system stores views as markdown and renders them to HTML.

Like Perspective stores components as JSON, we store them as markdown.

Structure

views/ - Page definitions (dashboard.md, chazon.md, demo.md)

components/ - Reusable UI components (searchbar.md, container.md, etc.)

layouts/ - Page layouts (default.md)

Available Views

📊 Dashboard

System dashboard with stats and controls

views/dashboard.md

🌌 Chazon

Boot screen and terminal interface

views/chazon.md

🔍 Demo

Multimodal search demonstration

views/demo.md

Build Templates

python templates/build.py - Build all templates

python templates/build.py dashboard - Build specific template

python templates/build.py --watch - Watch mode

Dynamic Rendering

Render templates dynamically in browser:

await TemplateEngine.loadTemplate('dashboard');

await TemplateEngine.render('dashboard', document.body);

Components

  • Container - Generic container
  • SearchBar - Search input with button
  • ButtonGroup - Group of buttons
  • BootScreen - Terminal-style boot screen
