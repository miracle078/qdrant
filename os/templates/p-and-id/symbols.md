# P&ID Symbols (ISA-5.1 Standard)
**Type:** Reference | Instrumentation Symbols

ISA-5.1 compliant symbols for process and instrumentation diagrams.

## Instruments

| Symbol | Name | Description |
|--------|------|-------------|
| [AT] | Analyzer/Transmitter | Composition/quality analysis |
| [FT] | Flow Transmitter | Flow rate measurement |
| [PT] | Pressure Transmitter | Pressure measurement |
| [TT] | Temperature Transmitter | Temperature measurement |
| [LT] | Level Transmitter | Liquid level measurement |

## Controllers

| Symbol | Name | Description |
|--------|------|-------------|
| [PID] | PID Controller | Proportional-Integral-Derivative control |
| [PLC] | Programmable Logic Controller | Programmable automation controller |
| [HMI] | Human-Machine Interface | Operator interface |
| [DCS] | Distributed Control System | Distributed process control |

## Equipment

| Symbol | Name | Description |
|--------|------|-------------|
| [P] | Pump | Fluid pump |
| [V] | Valve | Control or isolation valve |
| [T] | Tank | Storage tank |
| [R] | Reactor | Chemical reactor |
| [M] | Motor | Electric motor |
| [H] | Heat Exchanger | Heat transfer equipment |
| [C] | Compressor | Gas compressor |

## Connection Types

- **OPC UA** - Unified automation protocol

- **gRPC** - Remote procedure calls
- **REST** - HTTP API calls
