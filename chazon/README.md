# 🌌 Chazon OS - חזון

**φ-Balanced Computing | ISA-Compliant | Client-Side Only**

## What is Chazon?

Chazon (חזון - Hebrew for "Vision") is a pseudo-OS that runs entirely in your browser. It executes programs written in Markdown format, following ISA automation standards.

## Architecture

```
chazon/
├── core/          # OS kernel, markdown compiler, CLI
├── agents/        # CI/CD agents (ISA-95 L0-L4)
├── ui/            # Desktop environment, window manager
├── isa/           # Standards & compliance (95/88/18.2)
└── programs/      # Sample programs (.md files)
```

## Key Features

- **All files < 250 tokens** - Ultra-modular design
- **Markdown programs** - Write code in .md files
- **Client-side execution** - No backend required
- **ISA standards** - Full L0-L4 hierarchy
- **CI/CD agents** - Automated testing & deployment
- **Regulatory mapping** - 21 CFR Part 11, EU Annex 11
- **φ-balanced** - Golden ratio (1.618) throughout

## Quick Start

1. Open `chazon.html` in your browser
2. Wait for boot sequence
3. Type `help` to see available commands
4. Run `demo` to see sample programs

## Commands

```
help          - Show available commands
ls            - List programs
run <file>    - Execute a program
cat <file>    - View program source
demo          - Run demo programs
clear         - Clear terminal
```
