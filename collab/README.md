# Collaboration Directory

This directory is organized for multi-agent and multi-user collaboration on the Qdrant project.

## Directory Structure

- **agent-1/**: Work area for Claude Code Agent 1
- **agent-2/**: Work area for Claude Code Agent 2
- **tom/**: Work area for Tom (human collaborator)
- **miracle/**: Work area for Miracle (human collaborator)

## Usage

Each subdirectory serves as a workspace for the respective agent or user to:
- Draft ideas and experiments
- Share notes and progress updates
- Coordinate work without conflicts
- Stage work before merging to main codebase

Feel free to create files, take notes, and collaborate across directories!
