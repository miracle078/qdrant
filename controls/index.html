📖 About the Controls Portal
This portal provides access to all industrial automation and control systems. The architecture follows ISA-95 standards with L4 (Business), L3 (MES), L2 (Supervisory), L1 (Control), and L0 (Field) layers. Navigation is UUID-based for path independence, and all screens are rendered from JSON definitions following the Ignition Perspective model.
